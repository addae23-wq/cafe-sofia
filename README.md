# Café SofIA

Proyecto React + Vite generado a partir del prototipo aprobado en el chat de Claude.

## Cómo abrir este proyecto

1. Abrí esta carpeta en Visual Studio Code (`File → Open Folder`).
2. Abrí una terminal dentro de VS Code (`Terminal → New Terminal`).
3. Ejecutá:

   ```
   npm install
   npm run dev
   ```

4. Vas a ver una URL local (algo como `http://localhost:5173`). Abrila en el navegador para ver tu café funcionando.

Este proyecto todavía no está conectado a datos reales ni tiene backend: es la versión en código del prototipo navegable que ya evaluaste y aprobaste.
